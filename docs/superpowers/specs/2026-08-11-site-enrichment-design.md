# Site Enrichment Design — mattpocock-skills-zh-tw

- Date: 2026-08-11
- Status: Approved
- Scope: Enrich the bilingual reading site (`mattpocock-skills-zh-tw`) with content distilled from three primary sources: the AI Engineer World's Fair talk "Building Great Agent Skills: The Missing Manual", the aihero.dev/skills page, and the growthhackers.tw article on writing great agent skills.

## Goals

1. Teach the reader the **four-gate skill checklist** (Trigger / Structure / Steering / Pruning) that Matt Pocock encoded into the `writing-for-agents` skill — currently the site only has the skill reference page, not a teaching page.
2. Add the **six-zone organization** (Getting Started / Main Flow / Shaping / Upkeep / Productivity / Reference) from aihero.dev/skills as an alternative lens over the skill set.
3. Add a **version history (Changelog)** page from the translated `CHANGELOG.md`, highlighting renames and milestones.
4. Surface all three via new homepage entry cards.

## Approach

Data-driven + generator integration (Option A). Teaching content lives as a bilingual block-pair Markdown doc; the site is generated by `scripts/build-site.py`.

## Deliverables

### Phase 1 — Teaching page `write-great-skills.html`

- New `docs/guide/how-to-write-great-skills.md` — bilingual EN/ZH block-pair content following the translation-workflow conventions (same block structure the skill pages use).
- New `guide_page()` in `build-site.py` — reads the guide md, renders via existing `split_blocks` / `pair_blocks` / `render_md` / `rewrite_links`, emits a two-column bilingual page.
- Content sections:
  - Skill hell (opening)
  - ① Trigger — model-invoked vs user-invoked, context load vs cognitive load, context pointer
  - ② Structure — steps + reference, keep SKILL.md small, progressive disclosure, branches
  - ③ Steering — leading words (vertical slice), legwork / hiding future steps
  - ④ Pruning — single source of truth, sediment, no-ops, deletion test
- Embedded YouTube iframe: `https://www.youtube.com/embed/UNzCG3lw6O0`
- Transcript highlights with timestamps (from local VTT archive).
- Cross-links to `writing-for-agents/SKILL.html` and `SKILL-MECHANICS.html`.

### Phase 2 — Six-zone page `zones.html`

- New `ZONES` data structure + `zones_page()` in `build-site.py`, reusing `.level` / `.card` styles.
- Zone assignments (skills may appear in multiple zones):
  - Getting Started 入門: `setup-matt-pocock-skills`, `ask-matt`
  - Main Flow 主流程: `grill-with-docs`, `grill-me`, `to-spec`, `to-tickets`, `implement`, `tdd`, `code-review`
  - Shaping 塑形: `wayfinder`, `triage`, `prototype`, `to-questionnaire`, `research`
  - Upkeep 維護: `diagnosing-bugs`, `improve-codebase-architecture`, `resolving-merge-conflicts`, `triage`
  - Productivity 生產力: `grilling`, `handoff`, `teach`, `wait-what`, `writing-for-agents`
  - Reference 參考層: `domain-modeling`, `codebase-design`, `writing-for-agents`, `research`, `wizard`
  - 其他 / 實驗室: misc + in-progress skills (noted as outside aihero's promoted taxonomy)

### Phase 3 — Changelog page `changelog.html`

- New `changelog_page()` in `build-site.py`, sourced from the translated `CHANGELOG.md` plus aihero v1/v1.1/v1.2 summary titles/dates.
- Readable version timeline: new skills / renames / removals / milestones.
- Renames highlighted: `writing-great-skills → writing-for-agents`, `to-prd → to-spec`, `decision-mapping → wayfinder`.
- Skill names link back to their pages.

### Phase 4 — Homepage & styles

- `index_page()`: add 2 entry cards (📝 如何寫出好技能, 🧭 六大區) → 5 total; Changelog link under the About card.
- `assets/site.css`: video embed panel, changelog timeline, guide block styles (small additions).
- Add new entries to `back-link` on site pages.

### Phase 5 — Verification

- Rebuild: `python scripts/build-site.py`
- Local preview: `python -m http.server 8000` — check rendering, iframe, links, RWD.
- Update `README.md`; commit + push.

## Success Criteria

- Four-gate checklist teachable from the site without watching the video (video is a companion).
- Six-zone page renders all 35 skills with correct links.
- Changelog page shows v1.0.0 → v1.2.2 evolution with rename highlights.
- No broken internal links; bilingual pages match existing site style.
