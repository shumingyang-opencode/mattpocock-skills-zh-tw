L1起手Start here — align on the idea
ask-matt技能路由器詢問哪個技能或流程最符合你的情況。這個 repo 中技能的路由器。engineeringuser-invokedgrill-with-docs詰問 · 產文件鍥而不捨的訪談，磨利計畫或設計，過程中同時建立文件（ADR 與詞彙表）。engineeringuser-invokedgrill-me個人詰問一場持續的質詢，用來淬煉計畫或設計。productivityuser-invokedgrilling詰問原語持續質詢使用者關於一項計畫、決策或想法。當使用者想要壓力測試自己的想法，或使用任何「grill」觸發詞時使用。productivitymodel-invoked
L2規劃Plan — spec, tickets, route
to-spec生成規格把目前的對話轉成規格說明並發佈到專案 Issue 追蹤器——不訪談，只綜合你已經討論過的內容。engineeringuser-invokedto-tickets拆分 Ticket把計畫、規格說明或目前的對話拆成一組曳光彈 tickets，每個都宣告自己的阻塞邊，發佈到設定的追蹤器——在本機是每個 ticket 一個檔案、以文字表示邊，或在真正的追蹤器上用原生阻塞連結。engineeringuser-invokedwayfinder尋路 · 大規劃把一大塊工作——大得單一代理 session 裝不下——規劃成 Issue 追蹤器上決策 tickets 的共享地圖，逐一解決，直到通往目的地的路徑清晰為止。engineeringuser-invokedtriage分診讓 issues 與外部 PR 穿過分診角色的狀態機——分類、驗證、視需要 grill，並撰寫可供代理使用的簡報。engineeringuser-invokedto-questionnaire轉成問卷將一個您無法完全回答的決策轉化為一份由他人填寫的問卷。productivityuser-invoked
L3執行Build — test-first, prototype, debug
implement實作依規格說明或一組 tickets 實作一份工作。engineeringuser-invokedtdd測試驅動開發測試驅動開發。當使用者想以測試優先的方式建立功能或修 bug、提到「red-green-refactor」、或想要整合測試時使用。engineeringmodel-invokedprototype可拋棄原型建立一次性原型來回答設計問題。當使用者想確認某個狀態模型或邏輯是否合理，或想探索 UI 應該長什麼樣子時使用。engineeringmodel-invokedhandoff會話交接將目前的對話壓縮成一份交接文件，讓另一個代理接手。productivityuser-invokeddiagnosing-bugs故障診斷硬 bug 與效能回歸的診斷迴圈。當使用者說「diagnose」/「debug this」，或回報東西壞了/拋錯/失敗/很慢時使用。engineeringmodel-invoked
L4收尾Finish — review, maintain, unblock
code-review程式碼審查沿兩軸審查自某個固定點（commit、分支、標籤或合併基點）以來的變更——規範（軸）（程式碼是否符合此 repo 記錄的編碼規範？）與規格（軸）（程式碼是否符合原始 issue/規格的要求？）。以平行子代理執行兩種審查並排呈現。當使用者想審查分支、PR、進行中的變更，或說「review since X」時使用。engineeringmodel-invokedresolving-merge-conflicts解決合併衝突當你需要解決進行中的 git merge/rebase 衝突時使用。engineeringmodel-invokedimprove-codebase-architecture架構維護掃描程式碼庫找出深化機會，以視覺 HTML 報告呈現，然後對你挑選的那個進行 grilling。engineeringuser-invoked

domain-modeling領域建模建立並磨利專案的領域模型。當使用者想釐清領域術語或通用語言、記錄架構決策，或另一個技能需要維護領域模型時使用。engineeringmodel-invokedcodebase-design深模組設計設計深模組的共用詞彙。當使用者想設計或改進模組的介面、找深化的機會、決定接縫放哪裡、讓程式碼更容易測試或對 AI 更容易導覽，或另一個技能需要深模組詞彙時使用。engineeringmodel-invoked
support支援層Support — reach-for-anytime standalones
research背景研究針對高可信度的主要來源調查問題，並把發現寫成 repo 中的 Markdown 檔案。當使用者想要研究某主題、蒐集文件或 API 事實，或想把閱讀的苦差事委派給背景代理時使用。engineeringmodel-invokedteach多階段教學在此工作區內教導使用者一項新技能或概念。productivityuser-invokedwizard互動精靈產生一個互動式 bash wizard，引導人類走過只有他們能做的步驟。用於佈建基礎設施、設定憑證或 CI secrets、走訪陌生的第三方儀表板，或執行一次性遷移或切換。不要為代理自己能做的步驟叫用它。engineeringmodel-invokedwait-what重新闡述停下。上一則訊息沒有被理解 — 重新闡述它。productivityuser-invokedwriting-for-agents為代理寫作為代理撰寫文件。建立或編輯技能，或修改 AGENTS.md 或 CLAUDE.md 時使用。productivitymodel-invoked
