安裝指南

Install Guide · 把這包技能裝進 OpenCode 或 TRAE（IDE / CLI）
裝好之後，每個 repo 先跑一次 /setup-matt-pocock-skills，再從 /ask-matt 開始

這是什麼

這是一組「給 AI 工程師用的代理技能」的繁體中文版。技能就是一段可重用的指令集，裝進你的 agent（OpenCode / TRAE / Claude Code…）之後，agent 就能執行 /grill-with-docs、/tdd、/code-review 這類工作流。本 repo 是翻譯版：只改說明文字，指令、路徑、技能名全部照原樣，所以安裝方式跟上游完全一樣。

方式一（推薦）：skills.sh 一鍵安裝

skills.sh 是開放的技能安裝器，支援 OpenCode 與 TRAE。在終端機執行：

安裝到 OpenCode

npx skills@latest add shumingyang-opencode/mattpocock-skills-zh-tw -a opencode

安裝到 TRAE（國際版）

npx skills@latest add shumingyang-opencode/mattpocock-skills-zh-tw -a trae

安裝到 TRAE 中國版

npx skills@latest add shumingyang-opencode/mattpocock-skills-zh-tw -a trae-cn

加上 -g 表示裝到全域（所有專案都可用）；不加則裝進目前專案。想一次裝到兩個 agent 就同時寫 -a opencode -a trae。

  • 互動安裝時會問要裝哪些技能——務必勾選 setup-matt-pocock-skills，它是其他技能的前置。
  • 可以選擇 symlink（推薦，方便日後更新）或 copy 兩種裝法。
  • 日後更新：npx skills update。
  • 想先看看有哪些技能再裝：npx skills add shumingyang-opencode/mattpocock-skills-zh-tw --list

方式二：手動複製（OpenCode）

不習慣用安裝器的話，直接把技能資料夾複製進去。OpenCode 讀取技能的兩個位置：

  • 全域：~/.config/opencode/skills/（Windows 是 C:\Users\<你>\.config\opencode\skills\）
  • 專案：.agents/skills/（放在你的專案根目錄）

先把 repo 抓下來，再把 skills/ 底下每個技能資料夾複製進去。PowerShell 範例：

# 抓 repo
git clone https://github.com/shumingyang-opencode/mattpocock-skills-zh-tw.git
cd mattpocock-skills-zh-tw

# 複製全部技能到 OpenCode 全域目錄
Copy-Item -Path "skills\*\*" -Destination "$env:USERPROFILE\.config\opencode\skills\" -Recurse -Force

複製後，OpenCode 重新載入（或重開）就會看到這些技能。

方式三：手動複製（TRAE）

TRAE 讀取技能的位置（參見 TRAE Skills 文件）：

  • 全域（國際版）：~/.trae/skills/
  • 全域（中國版）：~/.trae-cn/skills/
  • 專案：.trae/skills/
# 複製全部技能到 TRAE 全域目錄（國際版範例）
Copy-Item -Path "skills\*\*" -Destination "$env:USERPROFILE\.trae\skills\" -Recurse -Force

開始使用

  1. 在 agent 中、每個 repo 執行一次 /setup-matt-pocock-skills——設定 issue tracker、分診標籤與文件位置。
  2. 不知道下一步該用哪個技能？輸入 /ask-matt，它會依你的處境推薦。
  3. 本網站就是這包技能的閱讀版：全景圖看關係，學習路線照順序學，每個技能頁都是中英逐段對照。

注意

  • 這是翻譯版；想用英文原版，請安裝上游：npx skills@latest add mattpocock/skills。
  • 不要兩套都裝——每個技能會出現兩次。
  • 翻譯只動說明文字，若遇問題請先比對上游行為。
